# ModMata —— 软件发布页

**ModMata（数模自动机）**：拖方块、连真线、跑真 Python 的画布式机器学习工具，数学建模专用。

> 本仓库只发布**成品软件**（zip 压缩包），不包含源代码。
> 源码为作者私有产权；**插件**在 [modmata-plugins](https://github.com/WilsonPing2007/modmata-plugins) 开源共享。

## 下载

前往右侧 **Releases** 页面，下载最新的 `ModMata-win32-x64-vX.Y.Z.zip`：

1. 下载 zip → 解压
2. 双击 `ModMata.exe` 即可运行（无需安装环境）
3. 首次运行自动生成内置插件库
4. 需要 Python 3（系统已装则自动探测，用于运行插件引擎）

## 安装第三方插件（可选）

1. 打开软件 → 设置 → 第三方插件
2. 关闭"受限模式"（按提示确认安全风险）
3. 浏览/搜索插件 → 点安装
